# Simple Linear Regression Analysis of Ozone Exceedance Days

## Overview
This project investigates the relationship between:
- Ozone exceedance days (>0.20 ppm)
- Seasonal meteorological index (850-mb temperature)

using simple linear regression in R.

## Objectives
- Perform exploratory data analysis
- Build a simple linear regression model
- Evaluate statistical significance
- Conduct regression diagnostics
- Generate confidence and prediction intervals

## Tools & Libraries
- R
- R Markdown
- Base R graphics
- Linear Regression Modeling

## Key Findings
- Positive relationship between meteorological index and ozone exceedance days
- The relationship was not statistically significant at α = 0.05
- Model assumptions were reasonably satisfied

## Files
- `ozone_analysis.Rmd` → full reproducible analysis
- `ozone_analysis.html` → rendered report
